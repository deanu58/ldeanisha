# L. Deanisha - Portfolio

A personal portfolio website for L. Deanisha, a fourth-year B.Tech student in Computer Science and Engineering (AI & ML) at Mohan Babu University.

## Live Demo

**https://deanu58.github.io/my persnol portfolio**

## About

This portfolio introduces who I am, my skills, education, internships and projects. It is built with plain HTML, CSS and JavaScript, with a purple theme and a range of animations.

## Sections

- **Home**: introduction with a typing subtitle
- **About Me**: short bio and skills
- **Educational Qualification**: B.Tech, Intermediate and 10th Class timeline
- **My Internships**: Siemens Data Science Master (EduSkills)
- **My Projects**: Weather App, Tic Tac Toe, Stopwatch, Landing Page
- **Contact Me**: email, GitHub and LinkedIn

## Features

- Purple theme with a light and dark mode toggle
- Typing effect and shimmering name in the hero section
- Floating particle background
- Mouse glow and sparkle trail (desktop only)
- Scroll reveal animations and a scroll progress bar
- Counting-up numbers for CGPA and percentages
- Flip cards on the project section (click or tap to flip)
- Responsive design with a mobile menu
- Respects the "reduce motion" setting for accessibility

## Built With

- HTML5
- CSS3
- JavaScript
